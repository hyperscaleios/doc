Components of HDA full rack

A full rack consist of 1 Master node, 1 Secondary Master Node, and 8 worker Nodes

Worker Node:
 1 CPU
 16G Ram
 100 GB HDD
 2 x 1G ethernet
 1 x 10G infiniband

Master Node:
 2 CPU
 32G Ram
 300 GB HDD
 1 x 10G infiniband

Secondary Master Node:
 2 CPU
 32G Ram
 300 GB HDD
 2 x 1G ethernet
 1 x 10G infiniband

10gb switch:
  1U Rack Mount   24 10G ports
  2 100G QSFP28 ports

HDA Cluster

Master node

Serves as the central entry point and management hub. It provides a single SQL interface to users, allowing them to interact with the cluster as if it were a single, large PostgreSQL database, while the underlying user data is processed in parallel across multiple segment nodes.

Secondary Master node

acts as a warm standby for the primary master instance to ensure high availability (HA). It provides a failover solution in case the primary master node becomes non-operational, allowing the cluster to continue operating without data loss.

Worker nodes

Responsible for storing user data and performing parallel processing of SQL queries dispatched by the coordinator node. They execute query plans independently on local data, handle data shuffles, and perform DML operations (inserts, updates, deletes) to maximize analytical performance.

Interconnect

24 Ports 10G L3 Switch
The backbone of Greenplum's parallel processing. It handles the intense network traffic generated during data redistribution, (MOTION nodes) during query execution.

Functions and Stored Procedures

The primary difference is that PostgreSQL functions cannot manage
transactions, whereas procedures can execute COMMIT and ROLLBACK commands.
Functions are built to compute and return values inside queries, while procedures
are designed to execute standalone batch operations and business workflows
If your main goal is to return query results into SELECT, a function is usually the better fit.

Core Component Breakdown

Feature           PostgreSQL Function             PostgreSQL Procedure
Transaction Control   No (COMMIT/ROLLBACK forbidden)   Yes (Allows full transaction control)
Return Mechanism   Requires a RETURNS clause        No RETURNS clause
Invocation Syntax     Called via SELECT or inside DML      Called via the CALL statement
Query Embedding    Can use in WHERE, JOIN, or SELECT    Cannot embed inside SQL queries
Output Method       Returns result sets or scalar values   Returns data only via INOUT parameters

Machine Learning

Machine learning help developers to create algorithms and models that allow computers to learn and make predictions or decisions without explicit programming. There are three types of machine learning techniques:
1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning

Deep Learning

Deep learning is inspired by the human brain's structure where billions of neurons communicate through signals.

Introduction to Neural Networks
Neural Networks are fundamentals of deep learning inspired by human
brain. It consists of layers of interconnected nodes called "neurons".

Components of Neural Networks:
Neurons
 • Inputs: Data values coming into the unit.
 •  Weights: Values that multiply the inputs to show their importance.
 • Bias: An extra value added to help the model fit the data.
 • Summing junction: Adds up all the weighted inputs and the bias.
 • Activation Functions: A math rule that decides the final output signal.
 • Loss Functions
 • Backpropagation
 • Learning Rate

Hyperparameters:
 •  Epochs
 •  Batch Size

Deep Learning Architecture
Below are foundational structures in deep learning:
 •  Perceptron

 •  Multi-Layer Perceptron
 •  Artificial Neural Networks (ANNs)
 •  Feedforward Neural Networks (FNN)
 •  Convolutional Neural Networks (CNN)
 •  Recurrent Neural Networks (RNNs)
 •  Long Short-Term Memory (LSTM) networks
 •  Gated Recurrent Units Networks (GRU)
 •  Optimization Algorithm in Deep Learning
The most common Algorithm are:
 •  Gradient Descent
 •  Stochastic Gradient Descent (SGD)

 •  Regularization
